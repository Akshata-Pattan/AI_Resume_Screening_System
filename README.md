# AI Resume Screening System

## Overview
AI Resume Screening System is a Flask-based web application that analyzes resumes, extracts skills, compares them with job requirements, and generates an ATS-style report.

## Features
- Resume upload
- Skill extraction
- Semantic matching
- ATS score generation
- PDF report generation
- Roadmap suggestions

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- NLP

## Installation

```bash
pip install -r requirements.txt
python app.py
```

- app.py
